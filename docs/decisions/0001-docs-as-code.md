# ADR-0001：所有过程文档与代码同库留痕

- 状态：Accepted
- 日期：2026-07-20

## Context

项目涉及九个平台规则、浏览器流程、需求、设计、证据要求和合规边界。若文档散落在聊天或本地文件，代码很快失去决策上下文。

## Decision

PRD、架构、设计、Adapter 协议、平台调查、测试报告、运维手册和架构决策全部存放在仓库，通过分支、Commit 和 PR 与代码共同审阅。

## Consequences

- 优点：可追踪、可对比、可回滚；新成员可从仓库恢复上下文。
- 成本：任何行为变更都需要更新文档；PR 审核项更多。
- 执行：CI 后续增加文档链接和 schema 一致性检查。
