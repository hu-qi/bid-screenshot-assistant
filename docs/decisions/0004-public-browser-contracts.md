# ADR-0004：真实平台优先使用公开浏览器页面契约

- 状态：Accepted
- 日期：2026-07-20

## Context

三个优先平台均提供公开公告页面，但技术形态不同：中国移动公开首页搜索入口尚需浏览器侦察；中国联通列表为强 JavaScript 单页应用；中国铁塔电子采购平台具有公开筛选列表和详情页。站点内部接口可能变化、未公开或带有风控语义。

## Decision

首版真实 Adapter 以 Playwright 操作官方公开页面为主，以页面指纹、可访问性定位器和详情 URL allowlist 构成契约。网络响应只作为解析和诊断辅助，不把未公开内部 API 作为唯一运行路径。

每个平台必须定义：

- 官方起点和允许域名；
- 列表/详情 URL 模式；
- 页面指纹；
- 搜索输入、提交、加载和无结果状态；
- 人工接管边界；
- 证据要求和回归样例。

## Consequences

- 优点：执行过程与用户实际看到的页面一致，截图天然具有证据价值；内部 API 改动时有 DOM 降级路径。
- 成本：浏览器执行较慢，需要更强的超时、并发和回归管理。
- 限制：如果官方公开页面无法稳定操作，应降级平台状态，不通过逆向或绕过控制强行恢复。
