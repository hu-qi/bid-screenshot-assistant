# ADR-0002：平台差异采用独立 Adapter

- 状态：Accepted
- 日期：2026-07-20

## Context

九个平台的登录、检索、分页、结果页和详情页差异很大。用一个通用 Prompt 临时操作会导致状态不可控、页面改版难定位、测试难复现。

## Decision

每个平台实现统一 `PlatformAdapter` 协议，平台选择器、页面指纹、无结果判定和恢复点全部留在独立模块。LLM 只用于输入清洗、候选语义排序和异常解释。

## Consequences

- 平台可独立开发、回归、启停和版本化；
- 初始开发量高于通用浏览器 Prompt；
- 公共协议变更必须兼容九个平台并新增 ADR。
