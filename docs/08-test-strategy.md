# 测试策略

- 状态：Accepted

## 1. 测试金字塔

### 单元测试

- 批量名称解析和去重；
- 状态聚合；
- 匹配规则；
- 文件命名、哈希和 manifest；
- 重试预算与幂等键。

### Adapter 契约测试

所有 Adapter 使用同一套测试，验证元数据、状态、证据和异常处理。

### 页面 Fixture 测试

保存脱敏 HTML/JSON 响应和页面指纹，测试选择器和解析，不依赖实时网站。

### 浏览器回归测试

在授权测试账号/Profile 上运行最小用例。失败时保存 trace、截图、DOM 摘要和网络错误。

### 端到端测试

创建任务 → 运行 → 证据 → manifest → ZIP → 交付记录。

## 2. 真实样例集

每个平台至少覆盖：

- 精确命中；
- 模糊命中；
- 多个同名结果；
- 无结果；
- 分页；
- 日期筛选；
- 详情打不开；
- 登录失效；
- 验证码；
- 平台异常/超时。

样例中的敏感信息必须脱敏，真实账号/Cookie 不进入仓库。

## 3. CI

每个 PR 运行：

```bash
python -m compileall src skills
pytest
```

真实网站浏览器测试不在普通 PR CI 中执行，使用受控定时流水线和专用凭据。

## 4. 验收报告

每个平台从 `pilot` 升级到 `enabled` 时提交：

- 测试样例清单；
- 成功率和状态分类准确率；
- 证据完整率；
- 人工接管结果；
- 已知限制；
- Adapter 版本与页面指纹。
