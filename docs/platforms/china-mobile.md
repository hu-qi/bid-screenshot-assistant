## 1. 已核实事实

官方首页公开展示：

- 全站搜索框，占位文案为“请输入公告标题包含的关键字”；
- 搜索分类包含“全部、招标采购公告、供应商公告、采购服务、系统通知、重点信息”；
- 主导航包含“招标采购公告”；
- 招标大厅包含“正在招标、即将开标、正在候选人公示”；
- 同一首页提供供应商、专家和员工登录，但公开公告搜索入口与登录入口分离；
- 网站明确提供电子招投标、账号密码、CA 和供应商协同等不同支持渠道。

## 2. 当前判断

- 公告标题搜索入口是公开页面能力；
- 首页内容可被公开索引，但搜索结果列表和详情 URL 结构尚未通过受控 Playwright 会话核实；
- 不应在现阶段硬编码历史旧版 URL 或依赖搜索引擎结果替代站内搜索；
- 第一版真实 Adapter 应优先使用浏览器 DOM 和可访问性定位，不直接假定存在稳定公开 API。

## 3. 页面契约（待浏览器确认）

### 起点

- URL：`https://b2b.10086.cn/`
- 页面指纹：出现“中国移动采购与招标网”“招标采购公告”“请输入公告标题包含的关键字”。

### 搜索输入

建议定位优先级：

1. `get_by_placeholder("请输入公告标题包含的关键字")`；
2. 与“全部/招标采购公告”等分类同一区域的文本输入框；
3. 页面语义定位失败时停止并返回 `PAGE_CHANGED`，不使用坐标猜测。

### 提交

待确认是回车、搜索图标还是按钮。真实侦察必须记录：

- 提交动作；
- 搜索后的 URL 是否变化；
- 结果区加载信号；
- 网络请求与响应状态；
- 无结果文案；
- 结果链接和详情 URL 模式；
- 分页方式。

## 4. 状态判定原则

- 页面可见“无匹配数据”只能在确认搜索已提交、查询词仍可见、结果区完成加载后判为 `NOT_FOUND`；
- 首页初始状态或请求尚未完成时出现“无匹配数据”，不得直接判为未命中；
- 搜索组件消失、分类栏消失或结果区持续不加载，判为 `PAGE_CHANGED` 或 `TIMEOUT`；
- 进入供应商/专家/员工登录不属于公开公告截图任务的正常路径。

## 5. 证据要求

- 搜索前页面指纹快照；
- 提交后的结果页全页截图；
- 查询输入框和结果状态必须在同一证据中可核验；
- 命中时保存详情页截图、标题、公告类型、原 URL 和日期；
- 未命中时保存明确完成搜索后的无结果状态。
