# 广东省公共资源交易平台初步调查记录

- 日期：2026-07-20
- Platform ID：`gd-ggzy`
- 状态：`discovery-pending`

## 1. 已确认

- 官方入口：`https://ygp.gdzwfw.gov.cn/`
- 平台由广东省人民政府办公厅主办，广东省政务服务和数据管理局承办；
- 首页属于交易系统入口，但公开抓取结果中曾出现 `404: undefined`；
- 同域下的广东省网上中介服务超市存在稳定公开列表和详情，但它是公共资源平台的一个具体业务子系统，不能替代整个“广东省公共资源交易平台”覆盖范围。

## 2. 当前风险

公开资料显示，主交易信息流可能使用动态页面和请求签名/加密。项目不会复制第三方逆向脚本、规避请求保护或硬编码未经浏览器确认的内部接口。

## 3. 实施策略

下一步只通过受控真实 Chrome 录制：

1. 官方入口；
2. 交易信息/公告搜索入口；
3. 一个明确命中项目；
4. 一个明确未命中项目；
5. 详情页；
6. 分页；
7. 登录、验证码或安全验证边界。

录制内容包括 accessibility snapshot、全页截图、DOM 摘要和脱敏网络请求清单，不读取 Cookie、Token、请求体秘密或验证码内容。

## 4. 禁止事项

- 不使用逆向出的动态签名绕过平台控制；
- 不把中介服务超市等子系统当作全平台结果；
- 不在当前阶段创建虚假的通用选择器；
- 不将首页 404 或空壳状态判定为 `NOT_FOUND`；
- 不进入报名、投标、付款、CA 或业务办理流程。

## 5. 进入 Adapter 实现的门槛

- 当前公开搜索 URL 和页面指纹已确认；
- 详情 URL 形态已确认；
- 明确命中与未命中均有截图；
- 页面不要求绕过安全控制；
- 至少形成 3 类脱敏 Fixture。
