# 广东政府采购 Adapter 变更影响

## 新增能力

- 官方全文检索与详情 API 证据；
- 门户公告截图尝试；
- 广东政府采购独立实验命令；
- URL、附件和状态契约测试。

## 不受影响

- 默认九平台 simulation Registry；
- 现有中国移动、中国联通、中国铁塔和公共服务平台 Adapter；
- Task/Run/Artifact 公共数据模型；
- JiuwenSwarm Skill 输入输出协议。

## 新风险

- 官方 API 参数或 channel 变化；
- 门户路由直接打开 403；
- 宽时间范围导致查询量上升；
- 附件域名变化。

所有风险通过默认关闭、`PARTIAL` 降级、域名白名单和生产回归门槛控制。
