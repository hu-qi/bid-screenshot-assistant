# 广东政府采购智慧云平台生产回归清单

## 样例

- [ ] 5 个明确命中项目；
- [ ] 3 个随机未命中项目；
- [ ] 1 个多结果项目；
- [ ] 1 个详情 API 异常或门户路由异常项目；
- [ ] 1 个带公开附件项目。

## 搜索

- [ ] 首页同站会话建立；
- [ ] 检索 API 参数仍有效；
- [ ] `code=200`、`rows` 和 `total` 结构稳定；
- [ ] 标题高亮还原正确；
- [ ] 分页总数和页码正确；
- [ ] 时间、地区、公告类型筛选可复现。

## 详情与证据

- [ ] 详情 API 字段稳定；
- [ ] 门户路由可通过站内导航打开；
- [ ] 门户直接打开 403 时能稳定归类为 `PARTIAL`；
- [ ] API/门户截图均包含来源与时间；
- [ ] metadata 与截图、manifest 一致；
- [ ] 同域附件 URL 正确，外部 URL 被过滤。

## 安全与运维

- [ ] 不进入电子卖场、交易工作台或登录流程；
- [ ] 限流/异常响应不会无限重试；
- [ ] Playwright Trace 和脱敏网络摘要已保存；
- [ ] 连续 5 个工作日回归通过后再评估 `pilot`。
