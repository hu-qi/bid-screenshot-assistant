# 广东政府采购智慧云平台验收标准

## 必须满足

- [ ] 生产 Chrome 下 10+ 样例可重复；
- [ ] `FOUND`、`NOT_FOUND`、`PARTIAL`、`PAGE_CHANGED` 分类准确；
- [ ] 检索 API 和详情 API 截图可校验；
- [ ] 门户公告页截图成功率达到试点阈值；
- [ ] 门户失败时不影响 API 证据保存；
- [ ] 标题、公告时间、采购人、项目编号和附件一致；
- [ ] 外部 URL 与欺骗域名被拦截；
- [ ] manifest 哈希可复算；
- [ ] 单条详情可独立重试；
- [ ] 无登录、报名、投标和付款操作。

完成后才可由 `experimental` 升级为 `pilot`。
