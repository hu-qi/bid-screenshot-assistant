# 运维手册

- 状态：Draft baseline

## 1. 关键指标

- 每个平台运行数、FOUND/NOT_FOUND/失败分布；
- 平均、P95、P99 耗时；
- 连续失败次数；
- PAGE_CHANGED 和 CAPTCHA_REQUIRED 数量；
- Artifact 写入和 ZIP 失败；
- 邮件/渠道交付失败；
- 队列深度和 Worker 饱和度。

## 2. 告警建议

- 单平台连续 5 次 `PAGE_CHANGED`；
- 平台 1 小时成功率低于 70%；
- 证据写入失败任意一次；
- 队列等待超过 15 分钟；
- 同一账号验证码频率异常上升；
- 邮件连续失败 3 次。

## 3. 页面改版处理

1. 自动停用受影响 Adapter 或降级为 `pilot`；
2. 保存失败页面、URL、可见关键词和 trace；
3. 创建 Issue，关联最近成功 Adapter 版本；
4. 更新平台调查文档和 fixture；
5. 修改 Adapter；
6. 跑契约测试和浏览器回归；
7. 灰度启用；
8. 更新 CHANGELOG 和验证时间。

## 4. 人工接管

操作员查看执行项，打开受控浏览器会话，完成登录/验证码后点击“继续”。系统创建新 attempt，从安全恢复点继续，并保留旧 attempt。

## 5. 备份与保留

- 数据库：每日备份；
- 对象存储：版本化或不可变策略；
- 默认证据保留期由业务/合规确认；
- 删除任务不立即物理删除证据；
- manifest 和审计日志保留时间不短于证据本身。
