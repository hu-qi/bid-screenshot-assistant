# 安全与合规

- 状态：Accepted baseline

## 1. 基本边界

本项目只自动化用户依法有权访问的公开页面或已授权账号页面。不得：

- 绕过验证码、扫码、人机验证、访问控制或频率限制；
- 使用未授权账号、共享泄露 Cookie 或伪造身份；
- 规避网站明确禁止的技术控制；
- 将抓取结果误称为官方法律证明；
- 在日志、截图文件名或 Git 历史中写入凭据。

## 2. 凭据与浏览器 Profile

- 密码、Token、SMTP 密钥只从 Secrets/环境变量读取；
- Chrome Profile 按环境、平台和账号隔离；
- Profile 目录不进入代码仓库和普通备份；
- 日志对 Cookie、Authorization、手机号、邮箱进行脱敏；
- 人工接管链接短期有效并限制访问者。

## 3. 抓取礼貌性

- 限制并发和查询频率；
- 优先使用公开检索和官方接口；
- 缓存重复查询；
- 尊重平台服务条款、robots/访问政策和公告内容版权；
- 平台返回限流/封禁信号时停止而不是升级重试强度。

## 4. 证据与隐私

截图可能包含账号名、联系方式或非目标公告信息。必须：

- 最小化截取范围；
- 对外分享前执行权限检查；
- 定义证据保留期和删除流程；
- 记录下载和邮件交付审计；
- 对对象存储启用加密和签名 URL。

## 5. 威胁模型摘要

主要威胁：凭据泄露、恶意页面内容影响 Agent、网页下载恶意附件、归档路径穿越、邮箱误发、证据篡改、无限重试触发封禁。

控制：域名 allowlist、下载隔离、文件类型/大小限制、路径规范化、SHA-256、收件人确认、重试预算、工具权限和人工审批。
